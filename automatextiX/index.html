STEP CONFIGURATION

A little automation goes a long way.

Add steps from the library. Select a step to configure it. Activate Connect, click an output port, then an input port to connect them. Click an edge to remove it in the inspector. Clean up arranges steps from left to right.

A manual trigger starts each run. Data is an array of JSON objects. Each active step receives items from incoming connections. Conditions route items to true or false; Merge concatenates active inputs. Inactive branches are skipped. Cycles and self-connections are rejected.

{"name":"{{ item.name }}","message":"Hello {{ item.name }}"}

Expressions resolve simple dotted paths from the current item. An exact expression preserves the JSON type. No JavaScript is evaluated. Web/HTTP steps make real browser requests when you run the workflow; CORS rules apply. AI call steps use the configured relay and can run 1–10 conversation rounds per item, with earlier replies retained and optional early completion. Command steps require a server executable allowlist and per-run confirmation. Workspace file steps list/read/write the shared virtual disk, including text, JSON and binary base64. Input templates supply virtual paths, file contents, prompts, argument arrays, standard input and request data; configured result fields pass outputs onward. Workflows only run while this page is open. They do not expose webhooks or run on a server schedule.
