# cncfiX · CNCF Landscape Studio

Local-first CNCF landscape diagram builder for mapping cloud native categories, subcategories, project maturities, and architecture notes.

## Features

- **Structured CNCF Landscape Model**: Categories, subcategories, and projects with maturity levels (`graduated`, `incubating`, `sandbox`, `platform`, `non-cncf`), OSS indicator, homepage/repo links, and architecture notes.
- **Built-in CNCF Catalog & Templates**: Quick-add CNCF projects (Kubernetes, Envoy, Istio, Prometheus, OpenTelemetry, Argo, Flux, Cilium, Falco, OPA, Harbor, etc.) or start from curated landscape templates.
- **Interactive Vector Preview**: Click cards in the SVG landscape to inspect/edit them, filter by maturity or keyword, and zoom/fit the canvas.
- **Exports & Imports**: Export standalone vector **SVG** (with embedded editable project metadata), **CNCF `landscape.yml`-compatible YAML**, or editable **JSON**.
- **Suite Integration**: Shared AI chat proposals with review/undo, workspace templates, Content Hub publishing, and virtual disk/project ZIP support.
