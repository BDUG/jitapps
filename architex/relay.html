Coding-agent model handoff

Start with a strong model. Once an implementation has relevant execution feedback and localized remaining work, optionally hand off once to a cheaper model. Shadow mode records decisions without switching. Readiness evaluation adds provider calls; no savings or quality gain is guaranteed.

Roles use saved profiles and their credentials. With no continuation configured, single-model behavior is retained. Set input support on each profile before handing off multimodal work. Role changes apply to new sessions; existing configured sessions require the same role configuration to resume.

Multi-model coding-agent collaboration

Optional solver and critic profiles discuss the same task and context. Later peers see earlier advice; the active or handoff model coordinates the final plan. Only the coordinator can propose runtime actions. Enabling this sends run context and references to the selected providers and adds provider calls.

Adaptive discussions prioritize critics for failures/verification and solvers for planning, rotating compatible peers within the call budget. Failed peers are reported and the coordinator continues with available feedback. Consensus never replaces actual checks. Settings and model revisions are retained per run; restore them or start a new run after changes.

Import / export

The configuration file is stored with owner-only permissions. Default exports omit keys.
